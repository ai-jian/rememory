# Game Brief: 旧物铺 · 拼忆

## In your words
是像想要做一个旧物修复的杂货铺，这样就是别人可以嗯拿着他的东西，然后过来，然后就会留下一段记忆，这个记忆就会被存在这边。嗯，就每一段每一个。旧的物品都承载着一份，嗯，独属于这个人的记忆，也映射着那个年代发生的一些事情，比较叙事类的交互游戏吧。

这三件事暂定的话能不能先出一个prototype来体验一下这个玩法和不合理？

Answers to the quick questions: 我现在准备睡觉了，所有的事情你来定，如果你觉得两个方向会差很多，那就做两版完全不一样的感觉的。

**Pitch:** 细看一件旧物，把看到的碎片拿给物主看，再亲手把这些词拼成一段完整的记忆。

**Genre:** detective + point-and-click *(guessed)*

**Controls:** 鼠标：点旧物上的地方细看；点一个词拿起它，再点记忆里的空格填进去，或者点客人把它拿给对方看。F 翻面，按住空格显示所有能看的地方，H 提示，M 静音。*(provisional)*

**Question:** 把线索拼成记忆的推理玩法成立吗？自己拼出来的故事，会不会比修出来的更让人在意？

**Hooks:** 记忆是一段有空格的话，词要从旧物上看出来，或者从物主嘴里问出来；拼对了才知道该怎么修。最后要自己认出两段记忆里的同一个人。

**Intent:** soft or no failure *(provisional)*

## Look and references
- Look: 铅笔版画感 *(provisional)*。米色纸面，旧物是黑色铅笔线稿，线条会轻轻抖动，暗部用斜排线。全屏只有黑、白、灰，琥珀色只给"记忆的词"和拼好的记忆用。客人是半身线稿。签名细节：线条像手绘动画一样微微抖动。every figure drawn, no emoji, no plain circles.
- References: The Case of the Golden Idol（把词填进空格来确认发生了什么）*(guessed)*；Return of the Obra Dinn（黑白线条，只靠观察）*(guessed)*；Pentiment（纸面和手绘线条的质感）*(guessed)*。
- View: 2D · Camera: 固定，一张纸面：左边旧物，右边记忆和词 *(provisional)*

## First minute
周奶奶把一块停掉的手表放在纸上，说"它停了很多年了"。玩家点表蒙，看到指针停在 7 点 40 分，一个琥珀色的词"7点40分"落进词盘。右边的记忆是一段有六个空格的话。玩家把"7点40分"拿给周奶奶看，她说"那是我下夜班的钟点"，又得到一个词。第一个空格填上，琥珀色亮起来。

## Challenge
没有失败，也没有计时 *(provisional)*。第一件手表有 6 个空格，词里混着用不上的；填满以后只告诉你"有几处对不上"，不告诉你是哪几处（大约第 2 到 4 分钟）。第二件收音机的词要追问两层才问得出来。最后要从三个人里认出"往厂里走的那个人"是谁。H 提示先说方向，再帮你清掉一处填错的。

## Core loop
- 客人放下旧物，说一句话
- 点旧物细看，得到词
- 把词拿给客人看，问出更多的词
- 把词填进记忆的空格，全对了，记忆就完整了
- 知道了故事，再决定怎么修；客人取走旧物，记忆留在店里

## Goal & fail state
- 拼出两段记忆，再认出它们里面的同一个人。没有失败；一局大约 8 到 10 分钟，随时可以"重新开张"。

## Features
- [x] 手表：四处可以细看的地方，正反两面
- [x] 收音机：六处可以细看的地方，后盖要先打开
- [x] 词盘：看到的和问到的词都收在这里，有用不上的词
- [x] 把词拿给客人看，问出新的词
- [x] 有空格的记忆：填满后告诉你有几处对不上
- [x] 拼对以后的修法选择，改变客人取件时说的话
- [x] 最后一问：认出两段记忆里的同一个人
- [x] 按住空格显示所有能看的地方；H 提示先小后大

## Out of scope
- 很多件旧物、很多位客人：grow it
- 选项会改变故事走向的对话：add it as a feature
- 亲手操作的修理（擦、撬、拧）：见另一版《旧物铺 · 暖灯》
- 杂货铺的经营（买卖、钱）：add it as a feature
- 存档：grow it

## Build order
1. 一小段完整体验：手表和收音机两段记忆，加最后一问。没有失败。
2. 更多旧物，词可以跨物品使用。
3. 店铺随年代变化。

# Game Brief: 旧物铺 · 暖灯

## In your words
是像想要做一个旧物修复的杂货铺，这样就是别人可以嗯拿着他的东西，然后过来，然后就会留下一段记忆，这个记忆就会被存在这边。嗯，就每一段每一个。旧的物品都承载着一份，嗯，独属于这个人的记忆，也映射着那个年代发生的一些事情，比较叙事类的交互游戏吧。

这三件事暂定的话能不能先出一个prototype来体验一下这个玩法和不合理？

Answers to the quick questions: 我现在准备睡觉了，所有的事情你来定，如果你觉得两个方向会差很多，那就做两版完全不一样的感觉的。

**Pitch:** 在暖灯下的工作台上亲手擦、撬、拧一件旧物，修到哪一步，物主的记忆就浮出哪一段。

**Genre:** cozy-cleanup + point-and-click *(guessed)*

**Controls:** 鼠标：点工具拿起，在旧物上按住拖动来干活；也可以按住空格让当前工具干活。数字键 1-4 换工具，H 提示，M 静音。*(provisional)*

**Question:** "记忆是修出来的"这个玩法成立吗？亲手修的手感，能不能让人在意物主的故事？

**Hooks:** 每一下修理都直接露出一条线索；修法（修得像新的，或留着痕迹）改变留下的记忆和客人的反应。两件旧物指向同一场雪。

**Intent:** soft or no failure *(provisional)*

## Look and references
- Look: 暖色手绘工作台 *(provisional)*。俯视木桌，一盏台灯的暖光打在中间的绿色毛毡垫上，四周暗下去。形状圆润，颜色有角色：黄铜和米白是旧物，砖红是工具把手，墨绿是垫子，琥珀色只给"记忆"用。记忆片段是褪色的小幅水彩感画面，带飘雪。签名细节：台灯光圈里慢慢飘的灰尘。every figure drawn, no emoji, no plain circles.
- References: PowerWash Simulator（每一下都看得见变干净）*(guessed)*；Unpacking（物品讲一个人的生活）*(guessed)*；Assemble with Care（修旧物的题材，只取"修理是亲手做的"这一点）*(guessed)*。
- View: 2D · Camera: 固定俯视，一张工作台占满窗口 *(provisional)*

## First minute
开场是店里的工作台，门铃响，周奶奶把一块停掉的上海牌手表放在毛毡垫上，只说一句"它停了很多年了"。绒布在发光，玩家拿起它在表蒙上来回擦，灰雾一下一下被擦开，露出停在 7 点 40 分的指针，第一条线索落进右边的记忆条。接着拿起撬刀撬开后盖，看到刻着的"1987.12.24"。不到一分钟，第一段记忆画面浮出来：一场大雪。

## Challenge
没有失败，也没有计时 *(provisional)*。难点是"看懂"而不是"做对"：第一件手表每一步都有发光提示；第二件收音机不再发光提示，要自己判断先用哪件工具、接哪根线、把调谐旋到哪里（大约第 3 到 5 分钟）。每件旧物最后有一个不能撤回的修法选择，它决定客人取件时说什么。H 键提示先给小的，再给大的。

## Core loop
- 客人放下旧物，说一句话
- 选工具，在旧物上动手：擦、撬、接线、上发条、调台
- 每完成一步，露出一条线索，记忆画面多亮一块
- 最后选一种修法，客人取走旧物，记忆留在店里的架子上
- 下一位客人进门

## Goal & fail state
- 修好两件旧物，架子上留下两段记忆，并看到它们指向同一场雪。没有失败；一个完整的一局大约 6 到 8 分钟，随时可以"重新开张"。

## Features
- [x] 手表：擦表蒙、撬后盖、上发条三步，每步露出一条线索
- [x] 收音机：掸灰、开后盖、接断线、调台四步，每步露出一条线索
- [x] 每一下都看得见：擦到哪里干净到哪里，快擦完时剩下的自己清掉
- [x] 每件旧物一个修法选择（像新的 / 留着痕迹），改变记忆的最后一句和客人的反应
- [x] 记忆画面随线索一块一块亮起来
- [x] 店里的架子：修完的旧物记忆摆上去，两段记忆之间连出"同一场雪"
- [x] 提示键：先小提示，再大提示
- [ ] 完成一步有一声轻响，修完一件有一声更长的

## Out of scope
- 很多件旧物、很多位客人：grow it
- 能追问、会改变故事的对话：add it as a feature
- 用修理挣钱买更好的工具：change it after play
- 杂货铺的经营（买卖、钱）：add it as a feature
- 存档：grow it

## Build order
1. 一小段完整体验：手表和收音机两件旧物，从开张到架子上连起两段记忆。没有失败。
2. 更多旧物和客人，零件可以互相借用。
3. 店铺随年代变化。

**Kill condition:** 如果玩的人修完两件，说不出任何一位物主的事，只记得"擦了东西"。
